Create Token API

Request

HTTP Method:
GET
URL:
{{$.URL "/api/create_token"}}
Response format:
json
Fields:
  • api_key - Required (See the application preferences). Not needed if the Authorization: Bearer header is used. See Authentication.
  • id - Required, package id to create a token
  • mail - Required, mail address of an owner of the application. The token installs the package as this user.
  • expire_hour - Optional, expiration time specified in units of hour

Response

Status:
200 OK
Sample response:

  "package_url": "{{$.URL "/package?id=3"}}",

Sample Curl

curl -H "Authorization: Bearer {application_api_key}" "{{$.URL "/api/create_token?id={package_id}&mail={mail_address}&expire_hour={expire_hour}"}}"

Caveats

The type of numeric fields (id, file_size, etc.) are indeterminate and can be either string or number.
